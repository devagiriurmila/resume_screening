# UiPath RPA package

The web application works **without** UiPath. UiPath automates the repetitive, human-free parts around it:
picking up resume PDFs from a folder, running them through the engine, collecting the Excel report and logging results.

| File | Purpose |
|------|---------|
| `workflow_design.md` | Step-by-step build guide: packages, every activity with properties, retry and exception handling, testing/debugging. |
| `variables.md` | All variables, arguments and Config values with exact UiPath types. |
| `selectors.md` | Stable selectors for the local demo job page (and why they are stable). |
| `flows/*.mmd` | Mermaid flowcharts (see `flows/README.md`). |
| `uipath/README.md` | Notes about project files, and a ready-to-copy `Config.json`. |

## Honest note about project files
A `.xaml` workflow or `project.json` generated by hand (outside UiPath Studio) is very likely to be rejected by Studio
because it must match your exact Studio/package versions. So this package gives you **precise build instructions** instead of
an invented project file. Building it takes roughly 30-45 minutes and you will understand every activity.

## What the robot calls
Everything heavy is done by one tested Python entry point: `scripts/process_resumes.py`
(exit codes 0 = all good, 1 = some files failed, 2 = fatal; last stdout line = JSON summary).
